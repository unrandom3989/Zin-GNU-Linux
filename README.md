# Zin-GNU-Linux
ZIn GNU/Linux es una distribucion basada en NixOS con escritorio GNOME y algunas utlidades extra, decir que esta distribucion no les puede llegar a gustar a todos ya que esta echa a partir de mi gusto y a mi flujo de trabajo, decir que esta en BETA y puede haber bugs o cosas que no cuadren asi que no esperen que sea la nueva Ubuntu

Actualmente la distro usa GNOME con algunas extensiones, en general la estetica se inspira en Windows, viene con Firefox preinstalado como navegador y algunas apps de GNOME quitadas, de echo viene con alacritty instalado y flatpak habilitado, tambien soporte para AppImages, la tienda de GNOME ya instalada, como suite de ofimatica tiene a OnlyOffice y esto es mas porque es mas compatible (en mi experiencia) con el formato de el office de Microsoft, probablemente en todo lugar diga NixOS pero es porque esta en BETA BETA PERO BETA, bueno lo ire actualizando poco a poco pero por ahora espero que les guste :)
